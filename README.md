# Inner Compass Collective

Psychospiritual Business & Leadership

---------------------------------------

Build a modern, premium web application for a "Psychospiritual Business & Leadership" platform. The design must feel professional, deeply calming, and highly credible—blending executive business consulting with holistic, spiritual psychology. 

### 1. DESIGN SYSTEM & VIBE

- Theme: "Elevated Mindfulness." Clean, minimalist corporate structure meets organic, soulful aesthetics.

- Palette: Grounding deep forest green, soft sage, warm sand/cream background (#FDFBF7), with sophisticated gold/bronze accents. Strictly avoid harsh pure blacks or bright neon colors.

- Typography: Elegant serif headers (like Cormorant Garamond or Playfair) paired with highly readable, clean sans-serif body text (like Inter).

### 2. PAGE STRUCTURE & NAVIGATION

Create a responsive, multi-page application with a sticky navigation bar (Logo, Services, Assessment, About, Contact) and a Call-to-Action button ("Book Catalyst Session").

- Home Page: High-impact hero section with a compelling value proposition: "Aligning Executive Strategy with Inner Wisdom." Features a client testimonial carousel, recent insights, and an overview of the core methodology.

- Services Page: Split into three distinct tiers using clean, interactive cards: 

  1. Mindful Leadership Coaching (1-on-1 for executives)

  2. Psychospiritual Branding Strategy (For purpose-driven founders)

  3. Corporate Wellness Modules (B2B team consulting)

- Assessment Page: A dedicated, interactive tool (detailed below).

- Contact/Booking Page: A clean inquiry form and an embedded calendar placeholder UI.

### 3. ADVANCED INTERACTIVE FEATURE: "THE ALIGNED LEADER ASSESSMENT"

Build a multi-step quiz directly on the platform to help users evaluate their business alignment and burnout levels.

- Layout: A sleek, centered card with a progress bar at the top.

- Step 1 (Mindset): "How do you make critical business decisions?" (Options: Purely analytical, Intuitive/gut feeling, Balanced logic and inner alignment).

- Step 2 (Energy): "Rate your current burnout level from 1 to 5." (Use a premium slider or custom button group).

- Step 3 (Purpose): "Is your company's core mission aligned with your personal spiritual values?" (Options: Fully aligned, Somewhat aligned, Completely disconnected).

- Results Logic: When submitted, show a beautiful, dynamic results dashboard. Include an animated score gauge, a personalized psychological profile paragraph, and a customized recommendation suggesting either a "Shadow Work Integration Workbook" or a "1-on-1 Executive Consultation."

### 4. TECHNICAL DETAILS & UI ELEMENTS

- Use Lucide icons for all visual anchors (e.g., Sparkles, Brain, Briefcase, ShieldCheck, ArrowRight).

- Include hover animations, smooth transitions, and subtle fade-ins for all cards and buttons to mimic a premium, meditative user experience.

- Ensure the layout is fully responsive for mobile and desktop screens. Include placeholder data so the app feels fully functional right out of the box.
